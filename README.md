I am not a hand-coding software engineer, and I say so up front: the code in my projects is AI-written under my direction. What I own is deciding what must be impossible, turning that into tests, and checking the tests actually bite.

## Featured project

**[outbound-guardrails-engine](https://github.com/juliuschua-ui/outbound-guardrails-engine)** is a cold-outreach pipeline that is *structurally unable to send a message*. It lints every draft against 12 mechanical rules, requires a human approval, and backs the rules with database triggers. A test fails the build if anyone adds send code. Runs a demo on synthetic data in one command, 1,230 tests.
